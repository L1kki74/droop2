# PuzoDrop — CS2 Cases

## Что работает

### Админ-панель (/admin)
- **Кейсы** — добавить / изменить / удалить, цена, картинка (URL), шансы скинов
- **Скины** — добавить / изменить / удалить, цена, картинка (URL), редкость
- **Промокоды** — создать, включить/выключить, удалить
- **Настройки** — название сайта, текст подвала, Telegram / Discord / VK / поддержка, лимиты

Данные сохраняются в localStorage браузера (пока без серверной БД).

### Клиент
- Шапка: только «Войти через Steam» (без баланса, пока не залогинен)
- Подвал: ссылки берутся из настроек админки
- Кейсы и открытие — из данных, которые ты добавил в админке

## Запуск

```bash
npm install
npm run dev
```

Сайт: http://localhost:3000  
Админка: http://localhost:3000/admin

## Деплой на Vercel

Залей на GitHub и подключи в Vercel. После деплоя админка работает так же (данные в localStorage каждого браузера).
